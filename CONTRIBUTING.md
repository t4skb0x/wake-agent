# Contributing

- Python 3.11+, standard library only. New runtime dependencies need a strong reason.
- `python -m unittest discover -s tests -t .` must pass. Tests use a fake agent binary and a local HTTP
  server, so they need no network, accounts or credentials.
- New runner: subclass `Runner` in `src/wakeagent/runners/`, register it in `__init__.py`, add argv tests.
  Keep `experimental = True` until it has been verified against the real binary.
- New channel: subclass `Channel` in `src/wakeagent/channels/`, register it, and add a test against the
  local HTTP server in `tests/test_channels.py`. Secrets come from env vars named in config, never values.
- `examples/quickstart` is generated by `wake init`. Edit `src/wakeagent/templates.py` and regenerate.
- Every behavior that came from a production failure is listed in `docs/LESSONS.md`. Keep it current.
